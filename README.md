# Курс оператора БПЛА

Автономный статический лендинг гражданского курса операторов БПЛА. Страница не использует формы и телефон: связь ведётся напрямую через MAX и Telegram.

## Локальный запуск

```powershell
python -m http.server 8011
```

После запуска откройте `http://127.0.0.1:8011/`.

## Состав

- `index.html` — основная страница;
- `privacy.html` — политика обработки данных;
- `course.css` — адаптивный дизайн;
- `course.js` — мобильное меню, cookie consent, Яндекс Метрика и цели;
- `assets/` — оптимизированные изображения и иконки.

## Аналитика

Яндекс Метрика № `112543150` загружается только после согласия посетителя. События:

- `course_max_click`;
- `course_telegram_click`;
- `course_faq_open`.

Выбор аналитики хранится 7 дней в cookie `bpla_course_analytics`.

## Перед публикацией

Публичная тестовая версия размещается по адресу `https://anthon88-nch.github.io/kurs-bpla-landing/` и содержит `noindex,nofollow`. Перед боевым продвижением нужно подтвердить параметры курса (срок, стоимость, расписание, оборудование и выдаваемый документ), при необходимости выбрать отдельный домен и только после этого менять индексацию и canonical.

Все основные иллюстрации созданы специально для этой страницы. Референсы использовались только как направление композиции и цвета.
